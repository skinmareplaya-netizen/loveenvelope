# LoveEnvelope — первая рабочая версия

Мобильный конструктор цифровых писем-конвертов. Статический фронтенд + Cloudflare Pages Functions + Cloudflare D1. Без регистрации получателя и отправителя.

## Уже есть

- 6 поводов: извинение, поздравление, свидание, признание, поддержка, своё послание.
- 4 темы оформления.
- Редактируемые имена, заголовок, текст и подпись.
- Предпросмотр с открывающимся конвертом и частицами.
- Необязательные звуковые эффекты/простая мелодия через Web Audio (никакие аудиофайлы не скачиваются).
- Публичные уникальные ссылки вида `/l/<id>`.
- Публичное чтение по API, сохранение в D1.
- Адаптивный дизайн, поддержка `prefers-reduced-motion`.

## Важно про приватность

Ссылка публичная: любой, кто её получил или угадал, может прочитать послание. Не добавляй пароли, адреса, личные документы или другую чувствительную информацию. В этой версии нет удаления посланий, панели владельца, ограничения срока хранения, антиспам-капчи или авторизации. Перед открытым запуском стоит добавить лимиты/Turnstile и возможность удалить ссылку. Уникальность ссылки не означает приватность.

## Развёртывание через Cloudflare Dashboard (без локальной установки)

### 1. Создай D1

1. Войди в Cloudflare: https://dash.cloudflare.com/
2. Открой **Workers & Pages → D1 SQL Database** (название пункта может немного отличаться).
3. Создай базу с именем `loveenvelope-db`.
4. Открой SQL Console этой базы, вставь всё содержимое `schema.sql` и выполни запрос.
5. В настройках базы скопируй Database ID.

### 2. Подготовь проект для GitHub

1. Создай репозиторий на https://github.com/new (например, `loveenvelope`).
2. Загрузи в репозиторий все файлы проекта, сохранив структуру каталогов:
   - `index.html`, `letter.html`, `styles.css`, `styles-extra.css`, `app.js`, `404.html`, `_redirects`, `schema.sql`
   - `letter.html`, `_redirects`
   - `functions/api/envelopes.js`
   - `functions/api/envelopes/[id].js`
   - `functions/l/[[path]].js`
3. Не публикуй секреты. В этом проекте API ключей нет; подключение D1 настраивается в панели Cloudflare Pages.

### 3. Создай Cloudflare Pages

1. Cloudflare Dashboard → **Workers & Pages → Create → Pages → Connect to Git**.
2. Подключи GitHub и выбери репозиторий.
3. Для plain HTML выбери framework preset **None**.
4. Build command оставь пустой (или `exit 0`, если поле обязательно).
5. Build output directory укажи `.` (корень репозитория).
6. Запусти deploy. Cloudflare выдаст адрес наподобие `https://loveenvelope.pages.dev`.

### 4. Подключи D1 к Pages Functions

В настройках Pages-проекта открой **Settings → Functions → D1 database bindings** (название может меняться):
- Variable name / binding: `DB`
- D1 database: `loveenvelope-db`
Сохрани изменения и запусти новый deployment. Настрой binding именно в Dashboard, так как проект не зависит от файла конфигурации Wrangler. Важно, чтобы имя binding было именно `DB`.

### 5. Проверь

1. Открой сайт.
2. Создай тестовый конверт.
3. Убедись, что появится публичная ссылка `/l/<id>`.
4. Открой ссылку в инкогнито или на другом телефоне.
5. Проверь API: `/api/envelopes` должен показать статус `ok`.

Если появляется ошибка о неподключённой базе, проверь `DB` binding и повтори deployment. Если маршрут письма отдаёт 404, проверь, что файл `_redirects` загружен в репозиторий и в нём есть правило `/l/*  /letter.html  200`.

## Развёртывание через Wrangler CLI (альтернатива)

Нужны Node.js и npm, затем:

```bash
npm install -g wrangler
wrangler login
wrangler d1 create loveenvelope-db
# Скопируй database_id в wrangler.toml, затем:
wrangler d1 execute loveenvelope-db --remote --file=schema.sql
wrangler pages deploy . --project-name=loveenvelope
```

После первого deploy подключи D1 binding `DB` в настройках Pages и при необходимости создай новый deploy. Для локального теста можно использовать `wrangler pages dev .` после установки и настройки D1; см. актуальную документацию Cloudflare.

## Ограничения бесплатного размещения

Cloudflare Pages подходит для статического сайта и Pages Functions. D1 имеет бесплатные квоты, но они могут меняться и превышение лимитов/изменение правил может повлиять на работу. Никто не может гарантировать бесплатную бесперебойную работу ровно два года. Проверь актуальные условия:
- https://pages.cloudflare.com/
- https://developers.cloudflare.com/pages/
- https://developers.cloudflare.com/d1/
